若娜瓦 AI 桌宠 · 余烬之间

启动：安装后双击桌面上的「若娜瓦AI桌宠」。角色与聊天为独立程序。
拖动：按住角色拖动；双击角色打开聊天；右键角色打开专属动作菜单。
托盘：右下角托盘图标可打开聊天、整理羽毛、找回角色或退出。

AI：聊天窗口右上角打开「连接与陪伴」，填写自己的 DeepSeek API Key。
接口默认 https://api.deepseek.com，模型默认 deepseek-v4-flash；可改为自己的可用模型。
桌宠与聊天共用同一轮生成，实时同步正文；长气泡会自动分段，也可点击箭头阅读。
未填写 Key 时仍可使用动作和本地陪伴短句。未随程序附带任何人的 Key。
可调整安静、均衡、活泼三档活跃程度，以及AI自言自语频率。
聊天窗口可以关闭而继续保留桌宠；从托盘选择退出才完全结束程序。

角色设计：保留白发、金色花纹瞳、眼状发饰、暗红翼与黑灰羽饰裙。
桌宠中的喝茶、点心、被摸头后的细小羞恼等为原创二创互动，并非官方喜好。
角色资料与来源在 reference/character-research.json；绘图提示词在 reference/image-prompts.json。

开发运行：npm install 后 npm start；打包：npm run dist。
程序只调用设置中指定的模型接口，不读取屏幕、你的文档或其他应用的内容。
